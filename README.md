# Robotics-CRC-Prelims
This repo contains practice problems from previous editions of the CRC (Canadian Robotics Competition) called Prelims. These are posted by the organizers in preparation for the Prpgramming part of the competition. 

## Adding your solution
If you wish to add your solution to this repo:
1. Create a separate branch and add your code to it.

<img src="https://docs.github.com/assets/cb-31579/mw-1440/images/help/branches/new-branch-button.webp" width=50%></img>

2. Clone the repo:
- Copy Link:
<img src="https://docs.github.com/assets/cb-60499/mw-1440/images/help/repository/https-url-clone-cli.webp" width=80%></img>

- Open your terminal or Git Bash.
- Change the current working directory to the location where you want to clone the repo.
- Type:
```commandline
git clone URL-THE-REPOSITORY

```

3. Navigate to the newly created local repository folder:
```commandline
cd Robotics-CRC-Prelims
```
4. Checkout your newly created branch:

```commandline
git checkout YOUR-BRANCH
```

4. Add your changes using GitHub Desktop, your IDE's Git functionalities or via command line:
```commandline
git add .
git commit -m "YOUR-COMMIT-MESSAGE"
```
